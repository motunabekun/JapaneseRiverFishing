# 2D釣りゲーム 仕様メモ

## コンセプト
日本の河川を舞台にした2D釣りゲーム。
プレイヤーは川辺を移動し、魚を釣り、売却してお金を得る。
最終的にはより大きな魚を釣ることを目標にする。

## 現在のMVP
- プレイヤー移動
- カメラ追従
- 釣りエリア
- キャスト
- アタリ
- 合わせ
- ファイト
- 魚GET
- 魚種・サイズ・重量表示
- 釣果記録
- 所持金
- Git管理

## 描画方針
- 当初予定していたクォータービューは採用しない。
- 視点は「川のぬし釣り（SFC）」に近いトップダウンビューとする。
- マップは見下ろし型とし、釣り場を広く見渡せることを優先する。
- プレイヤー移動は4方向または8方向を基本とする。
- 建物やオブジェクトには、トップダウン表示を崩さない範囲で簡易的な奥行きを持たせる。
